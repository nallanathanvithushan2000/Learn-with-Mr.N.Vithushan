Projectile motion

Launch from the top of a tower and compare the ideal path (dashed) with the path including air resistance. Set the drag coefficient to 0 for no air resistance.

Results

Theory

Two independent motions

Gravity acts only downward, so the horizontal and vertical motions can be treated separately. Split the launch velocity into components.

vₓ = v₀ cosθ v_y = v₀ sinθ

Without air resistance

Horizontally the speed is constant. Vertically the acceleration is −g.

x = v₀ cosθ · t
y = h₀ + v₀ sinθ · t − ½ g t²

Time of flight, range, maximum height

Set y = 0 and solve the quadratic for the landing time. The highest point is where the vertical velocity is zero.

T = [ v_y + √(v_y² + 2 g h₀) ] / g
Range = vₓ T
H_max = h₀ + v_y² / (2g)

From level ground (h₀ = 0) these reduce to Range = v₀² sin2θ / g, which is largest at 45°. From a raised launch point the best angle is below 45°.

Impact

The landing speed follows from the components at time T.

v = √(vₓ² + (v_y − gT)²)

Air resistance

At everyday speeds, drag opposes the velocity and grows with the square of the speed.

F_drag = ½ ρ Cd A v² a = −(F_drag/m)(v̂) + (0, −g)

Because the acceleration now depends on the velocity, there is no simple formula. The program steps the motion forward in tiny time intervals with the fourth-order Runge–Kutta method. Drag shortens the range, lowers the peak and makes the descent steeper than the climb.
